How it works

From pull request to a place everyone can see.

Branchglass turns every open pull request into an isolated, production-like environment—then keeps it in sync until the work is done.

Set up once. Automatic after that.

A branch's lifecycle · 01—04

  1. 01

    Connect your stack

    Authorize your code repository and cloud account. Branchglass works with the stack your team already owns.

    Repository Cloud account
  2. 02

    Open a pull request

    The PR event creates a fresh, isolated environment using production-like configuration and safe test data.

  3. 03

    Review at a real URL

    Developers, designers, and reviewers test together. Every new commit updates the same shareable preview.

  4. 04

    Merge, then disappear

    When the pull request is merged or closed, Branchglass automatically removes its environment and resources.
