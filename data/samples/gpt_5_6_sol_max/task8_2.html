What exactly is a temporary endpoint?
It is a URL created for the webhook test you are running. Point an HTTP-based webhook sender at it and Patchbay Cloud captures the incoming event so your team can inspect and work with it before connecting the integration to production.
Can I change an event before replaying it?
Yes. You can use a captured event as the starting point, modify its payload, and replay it to test how your handler responds. That makes it easier to reproduce malformed input, edge cases, and failure scenarios on demand.
Which kinds of webhooks will the beta support?
The initial private beta will focus on HTTP-based webhooks and common signing methods. More detailed compatibility information will be shared with beta participants as access opens.
How do engineering and support collaborate?
Teams can share event histories and debugging sessions, so a support handoff can include the captured request and the work already done. Engineers can pick up from the same evidence instead of reconstructing it from chat messages and screenshots.
Does Patchbay Cloud replace a production webhook gateway?
No. The first release is intentionally designed for testing and debugging webhook integrations before they connect to production systems. It gives pre-production events a dedicated place to land, be inspected, and be replayed.
What do I get by joining the waitlist?
You will receive private-beta updates and be considered for early access. The beta is a chance to use the focused first release and help shape the webhook debugging workflow with direct feedback.
