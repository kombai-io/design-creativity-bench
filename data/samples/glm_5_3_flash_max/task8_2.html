    What you get
    
        
    Everything you need to trust a webhook.
    
        
    Stop debugging blind with ngrok tabs and console.logs. Patchbay gives your team a proper workbench for every event that arrives.
    
      
    

      
    
        
    
          
    
          
    Instant temporary endpoints
    
          
    Spin up a disposable HTTPS endpoint in one click — or from the CLI. Point any provider at it and start receiving events in seconds. No deploys, no DNS, no tunnels to babysit.
    
        
    
        
    
          
    
          
    Full-fidelity inspection
    
          
    See every request exactly as it arrived: headers, query params, body, signing headers, and timing — syntax-highlighted and searchable across the whole event history.
    
        
    
        
    
          
    
          
    Replay any event
    
          
    Blast the same bytes back at your endpoint as many times as you need. Debug locally or against staging, then replay the fix without waiting for the provider to fire again.
    
        
    
        
    
          
    
          
    Mutate payloads & break things
    
          
    Edit payloads before replay, then simulate the ugly stuff on purpose — 500s, slow responses, malformed JSON, dropped connections — and see exactly how your code fails.
    
        
    
        
    
          
    
          
    Share the whole investigation
    
          
    Event histories and replay sessions are shareable by link. Loop in support with read-only context instead of pasting raw JSON into a Slack thread.
    
        
    
        
    
          
    
          
    Code that's already written
    
          
    Patchbay turns any captured event into a ready-to-paste handler — signature verification, parsing, and types included — in Node, Python, Go, and more.

    How it works
    
        
    From first event to fixed handler in minutes.
    
        
    No SDK required on the provider side. If it can reach a URL, Patchbay can capture it.
    
      
    
      
    
        
    
          01
          
    Create an endpoint
    
          
    One click gives you a temporary URL on hook.patchbay.dev. It lives as long as your debugging session does — delete it the moment you're done.
    
        
    
        
    
          02
          
    Point your provider at it
    
          
    Paste the URL into any dashboard, CLI, or internal service that delivers webhooks. Events land in the inspector in real time, signatures and all.
    
        
    
        
    
          03
          
    Replay, mutate, verify
    
          
    Fix your handler, replay the captured event, and confirm the signature checks out — all before anything touches a production system.

    import express from "express";
import { verifySignature } from "@patchbay/verify";

const app = express();

// Generated from evt_3Kd9xPq2Lm · invoice.payment_succeeded
// scheme: hmac-sha256 (timestamped v1)
app.post("/webhooks/payments", (req, res) => {
  if (!verifySignature(req, {
    scheme: "hmac-sha256",
    secret: process.env.WEBHOOK_SECRET,
  })) {
    return res.status(401).send("bad signature");
  }

  const { invoice, amount_paid, currency } = req.body;
  console.log(`invoice ${invoice} paid ${amount_paid} ${currency}`);

  res.status(200).json({ received: true });
});
    
        
    import os
from flask import Flask, request, abort
from patchbay import verify_signature

app = Flask(__name__)

# Generated from evt_3Kd9xPq2Lm · invoice.payment_succeeded
# scheme: hmac-sha256 (timestamped v1)
@app.post("/webhooks/payments")
def payments():
    if not verify_signature(
        request,
        scheme="hmac-sha256",
        secret=os.environ["WEBHOOK_SECRET"],
    ):
        abort(401)

    event = request.get_json()
    print(f"invoice {event['invoice']} paid "
          f"{event['amount_paid']} {event['currency']}")
    return {"received": True}, 200
    
        
    func handlePayments(w http.ResponseWriter, r *http.Request) {
  // Generated from evt_3Kd9xPq2Lm · invoice.payment_succeeded
  // scheme: hmac-sha256 (timestamped v1)
  ok, _ := patchbay.Verify(r, patchbay.HMACSHA256,
    os.Getenv("WEBHOOK_SECRET"))
  if !ok {
    http.Error(w, "bad signature", 401)
    return
  }

  var evt PaymentEvent
  json.NewDecoder(r.Body).Decode(&evt)
  log.Printf("invoice %s paid %d %s",
    evt.Invoice, evt.AmountPaid, evt.Currency)
  w.WriteHeader(200)
}
