How it works

A full preview environment for every pull request — without touching production.

Branchglass plugs into your existing workflow. Open a pull request, get a production-like environment with a shareable URL, and tear it down automatically when you're done.

01

Connect once

Link your code repository and cloud account. Branchglass learns your services, dependencies, and configuration — no per-project setup.

repo + cloud connected
02

Open a pull request

The moment a PR is opened, Branchglass spins up an isolated preview environment that mirrors your production setup.

PR #482 → environment
03

Test and review

Developers, designers, and reviewers get a shareable URL where they can click through and test the change with safe test data.

preview.branchglass.app/pr-482
04

Push, and it updates

Every new commit to the PR automatically updates the environment, so reviewers always see the latest state of the branch.

commit → rebuilt in minutes
05

Clean up automatically

When the PR is merged or closed, the environment is removed. No orphaned infrastructure, no surprise cloud bills.

merged → environment deleted
