Before you join

Straight answers for teams deciding whether MorrowSpec belongs in the next sprint.

What does MorrowSpec actually produce?

A hosted mock API derived from your OpenAPI specification. Clients call a real URL and receive realistic responses, errors, and test scenarios—not a downloaded JSON file.

How do specifications get into MorrowSpec?

You import an OpenAPI document or sync one from a code repository. When the underlying spec changes, the mock updates so teams are not pinned to a stale contract.

Who is the private beta for?

Software teams that need to build and test before backend services are ready, and that can work with OpenAPI-based REST APIs. Frontend, backend, QA, and product should be able to share the same environment.

Will you support GraphQL, gRPC, or SOAP in beta?

Not at first. The private beta is intentionally narrow: OpenAPI-based REST. If that is your world, join the waitlist. Other API styles are out of scope for the initial beta.

Is this a local CLI or a platform?

MorrowSpec is a developer platform. The point is a shareable hosted endpoint so the mock is not trapped on one engineer’s machine.
