Verified handler code, ready to commit

Patchbay Cloud learns the shape of your events and emits handlers with signature checks, idempotency, and structured logging baked in.

// Generated by Patchbay Cloud from ep_8f2a1c
import Stripe from 'stripe';
import { headers } from 'next/headers';

const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!);
const webhookSecret = process.env.PATCHBAY_SIGNING_SECRET!;

export async function POST(req: Request) {
  const body = await req.text();
  const sig = headers().get('stripe-signature')!;

  let event: Stripe.Event;
  try {
    event = stripe.webhooks.constructEvent(body, sig, webhookSecret);
  } catch (err) {
    return new Response(`Webhook error: ${err}`,
      { status: 400 });
  }

  switch (event.type) {
    case 'payment_intent.succeeded':
      await fulfillOrder(event.data.object);
      break;
    case 'invoice.payment_failed':
      await notifyBilling(event.data.object);
      break;
  }

  return new Response('ok', { status: 200 });
}

Frequently asked

Everything you wanted to ask

How is Patchbay Cloud different from ngrok or a local tunnel? +

Local tunnels give you a URL — Patchbay Cloud gives you a workflow. You get permanent event history, searchable timelines, team sharing, payload mutation, chaos rules, and generated handler code. It's the difference between a hose and a water treatment plant.

Will it work with providers you haven't pre-integrated? +

Yes. Any HTTP webhook works out of the box. We add first-class signing schemes and event schemas for popular providers, but the underlying endpoint is just HTTPS — you can inspect, replay, and verify anything.

Can I use it for production traffic, or only during development? +

During the private beta we recommend using Patchbay Cloud for pre-production and debugging only — endpoints are temporary and have retention limits. The Team and Platform plans add longer retention and SSO so you can use it as a managed observability layer too.

How do you handle webhook payloads that contain PII? +

Payloads are encrypted at rest with per-workspace keys, scoped to your team, and never used to train models. You can redact fields automatically (e.g. email, ssn_last4) before they're stored. We're pursuing SOC 2 Type II in Q3.

What signing methods are supported at launch? +

HMAC-SHA256 (raw and base64-encoded), Stripe-style t=…,v1=…, GitHub-style sha256=…, Svix-style, Shopify-style, and custom header schemes via the dashboard. AMQP and gRPC webhooks are on the roadmap for later in 2024.

When does the private beta end? +

We're onboarding cohorts of ~200 workspaces every two weeks. We expect general availability in Q3 2024. Everyone on the waitlist today keeps free Team-tier access for 6 months after GA.

Can I invite my whole team to a workspace? +

Yes. The Team plan includes unlimited collaborators per workspace with role-based permissions (Owner, Engineer, Read-only). Useful for letting support and product read the same event timeline without write access.
