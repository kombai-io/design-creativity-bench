Here’s how the Northstar team connected their existing stack to Branchglass.

01

Connect a code repository

Select northstar/storefront in your GitHub account. Branchglass watches pull request events and new commits.

02

Choose your cloud and configuration

Connect the Northstar AWS account in us-east-1. Use production-like configuration and a sanitized test data snapshot.

03

Pull request #142 is ready in 48 seconds. Share the preview, push updates, and merge. Cleanup happens automatically.

Built for safe reviews

Production-like.
Not production.

A realistic environment shouldn’t put real customer data at risk. Each pull request gets its own resources and safe test data in your cloud.

Isolated by pull request

Review #142 without changing production or interfering with the team’s other preview environments.

Safe data, realistic behavior

The checkout preview uses 1,248 sanitized sample records, so reviewers can exercise real flows without real customer information.

Temporary by design

When the pull request is merged or closed, Branchglass removes its environment and the cloud resources behind it.
