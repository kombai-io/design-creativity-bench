How it works

From spec to shareable API
in three steps.

Stop hand-writing stubs or waiting on staging. Import what you already have — your spec — and MorrowSpec does the rest.

01

Import or sync your spec

Drop in an openapi.yaml or connect a repo. MorrowSpec validates, versions, and watches for changes.

$ npx morrowspec sync ./openapi.yaml
✓ Validated 48 paths · 132 schemas
→ Watching main for changes…
02

Get a hosted endpoint

Instantly get a stable URL with realistic responses, errors, and test scenarios — no code to deploy.

GET /v1/orders/ord_8H2kQ → 200
GET /v1/orders/missing → 404
?scenario=checkout-fails → 402

When the spec changes, your mock updates. Everyone — frontend, QA, product — tests against the latest contract.

FAQ

Questions teams ask us.

How is MorrowSpec different from static mocks or Postman examples? +
Static mocks are hand-written and rot. MorrowSpec generates responses from your OpenAPI schemas — with realistic data, correct error shapes, pagination, and scenarios — and re-deploys automatically when the spec changes. One hosted URL stays correct for everyone.
What do I need to get started? +
Just an OpenAPI 3.x file (openapi.yaml/json), a URL, or a GitHub repo connection. We validate it, create a hosted endpoint like api.morrowspec.dev/e/your-env/v2, and you can start fetching in about 30 seconds.
How does syncing with my code repository work? +
Connect GitHub and point MorrowSpec at the spec path on a branch. On every push we diff the spec, version the mock (v41, v42…), redeploy, and flag breaking changes to subscribed channels. You can also pin an environment to a PR or tag.
Which APIs are supported in the private beta? +
The private beta initially supports OpenAPI-based REST APIs (3.x). GraphQL, gRPC, and event-driven protocols (AsyncAPI/WebSockets) are on the roadmap and prioritized by waitlist demand — tell us what you need in the form.
Is my specification and data private? +
Yes. Projects are private by default, endpoints use unguessable URLs with optional tokens, and generated data is synthetic — never your production data. You can delete environments and specs at any time.
When will I get access, and how much will it cost? +
We onboard new cohorts weekly and prioritize teams with an OpenAPI spec ready to sync. The private beta is free. We’ll share pricing before any paid plans launch — beta members lock in early-team benefits.
