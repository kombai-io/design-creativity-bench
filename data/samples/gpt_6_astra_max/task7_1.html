Quickstart guide

The pull request is the workflow.

A small addition to your stack. A big difference to your day.

  1. 01
    Connect your repository and cloud account

    Choose the repository you want to preview and the cloud account where environments should run. Our example uses acme/storefront and AWS us-east-1.

  2. 02
    Open a pull request as usual

    Branchglass provisions an isolated environment, applies production-like configuration, and loads safe test data. The sample PR runs web, api, and postgres services.

  3. 03
    Give your whole team a live URL

    Developers, designers, and reviewers can try the change in a real environment. Each new commit updates that same URL automatically.

GIT EVENTBRANCHGLASS TAKES CARE OF
Pull request openedCreating an isolated preview environment
New commit pushedUpdating the environment at the same URL
PR merged or closedRemoving the environment and its resources
