Conduit Lake Ecosystem & Connector SDK

Conduit Lake's unified runtime is designed with open standards. While our 8 primary verified engines provide turn-key performance, your team can ingest from and route to any custom infrastructure using standardized protocols.

Standard Open Protocols Supported:

  • gRPC Microservice Streams: High-frequency telemetry with sub-millisecond serialization.
  • Distributed Event Buses: Real-time broker partition rebalancing and consumer offset tracking.
  • Cloud Storage Multipart Dumps: Native support for Parquet, ORC, Avro, and JSONL data lakes.
  • REST & Webhook Ingest Endpoints: Signed HMAC authorization with automatic deduplication queues.
// Conduit Lake Custom Connector SDK (Rust Example) 
#[conduit_connector(version = "1.0")]
pub struct CustomStreamSource;

impl SourcePlugin for CustomStreamSource {
    fn poll_batch(&mut self) -> Result<ArrowRecordBatch> {
        let events = self.fetch_inbound_stream()?;
        Ok(events.into_arrow_with_schema_infer())
    }
}
