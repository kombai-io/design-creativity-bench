Design a pre-launch landing page for MorrowSpec.

MorrowSpec is a developer platform that creates realistic, shareable mock APIs from API specifications so software teams can build and test before backend services are ready.

The page should help software teams understand MorrowSpec and decide whether to join its private-beta waitlist.

Relevant product details:

- MorrowSpec imports an OpenAPI specification or syncs one from a code repository.
- It creates a hosted endpoint with realistic responses, errors, and test scenarios.
- The mock API updates when the underlying specification changes.
- Teams can share environments across frontend, backend, QA, and product work.
- The private beta will initially support OpenAPI-based REST APIs.
