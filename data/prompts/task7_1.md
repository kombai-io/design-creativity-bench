Design a “How it works” section for the marketing homepage of Branchglass.

Branchglass is a developer platform that automatically creates temporary, production-like cloud environments for software teams to test and review pull requests.

The section should help a prospective engineering team understand how Branchglass works and how it fits into their development workflow.

Product details you may find relevant:

- Branchglass connects to the team’s code repository and cloud account.
- Opening a pull request triggers an isolated preview environment.
- The environment uses production-like configuration and safe test data.
- Developers, designers, and reviewers receive a shareable URL where they can test the change.
- New commits automatically update the environment.
- The environment is removed when the pull request is merged or closed.
