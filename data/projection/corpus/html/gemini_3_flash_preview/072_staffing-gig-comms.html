Automated Dispatch Logic

When a new shift is published by a client, the system determines which workers are notified first. The current "Tiered Priority" model ensures that your highest-rated contractors (4.8 stars+) get a five-minute head start before the shift is broadcast to the general pool.

Consequences: Increasing the head start period improves quality but can lead to slower fulfillment for urgent "Last Minute" shifts (less than 4 hours until start).

Current setting: High-tier workers will receive SMS alerts 300 seconds before the standard pool.

Worker Response Windows

This defines how long a contractor has to accept an invitation before the offer is automatically rescinded and passed to the next available candidate. This is crucial for maintaining your Service Level Agreements (SLAs) with logistics partners.

If set to Dynamic, the system will compress the response window as the shift start time approaches. For example, a shift starting in 2 hours will only allow a 2-minute response window.
