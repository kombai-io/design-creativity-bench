The Chaplain Air Relay Network provides secure voice communications between military chaplains deployed across eight NATO bases in Europe and the central command facility at Ramstein Air Base. The system employs AES-256 encrypted VoIP over a dedicated SATCOM bearer with automatic failover to HF radio when satcom link degradation exceeds defined thresholds.

Primary Technology
Iridium SAT + AES-256 VoIP
Endpoints Active
8 bases · 1 CLTC hub
Uptime (rolling 30d)
99.94% · 14.2 min downtime

The AMRS replaces paper-based tech log processes with a fully digital system that synchronizes line maintenance findings in real time to the MRO planning engine. Built on an ARINC 618B compliant data link layer running over HF/VHF hybrid channels, the system supports both store-and-forward messaging and low-latency TCP bursts during VHF-range operations.

Protocol Stack
ARINC 618B / HDLC
Avg. Sync Latency
2.3 sec (HF) / 0.4 sec (VHF)
Records Processed
14,200 messages (180 days)

The Fructify dashboard integrates live AWOS and SIGMET data feeds into the FMS route planning workflow, allowing dispatchers to visualize fuel-optimal track alternatives before load submission. The system ingests NEXRAD radar composites, METAR/TAF bulletins, and satellite-derived cloud-top temperatures to generate four-quadrant efficiency ratings for each proposed diversion route.

The Synaptic mesh enables coordinated situational awareness among multiple aircraft operating in close-proximity formation routes across the North Atlantic track system. By sharing derived TCAS-level conflict probes via low-rate satcom burst packets, each aircraft gains enhanced deconfliction awareness beyond its own onboard sensors — effectively extending the detection horizon for traffic that may be obscured by weather or terrain masking.

Network Topology
5-node star-mesh hybrid
Packet Rate
1 Hz broadcast per node
Test Flights Completed
23 over Gander Oceanic
