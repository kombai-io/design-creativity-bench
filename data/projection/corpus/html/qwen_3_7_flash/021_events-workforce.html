Section Six

Communications Protocol & Escalation Hierarchy

All site communications follow a strict chain-of-command model. Radio frequencies are partitioned by function to prevent channel congestion. The escalation ladder defines the sequence of contacts when an incident exceeds an individual's authority level. Failure to follow the correct escalation path is grounds for immediate disciplinary action.

Escalation Ladder

  • Level 1 — Self: Handle within own scope using standard operating procedures. No radio call required for routine tasks.
  • Level 2 — Direct Supervisor: Contact via the relevant radio channel (#1–#7). Acknowledge receipt with code word. Expected response: < 3 minutes.
  • Level 3 — Band A Leader: Escalate if situation cannot be contained within 15 minutes or involves public safety. Use Channel #1 exclusively. Verbal briefing only — no text.
  • Level 4 — Site Director: Mandatory escalation for any incident involving injury, media presence, property damage over €5,000, or regulatory notification requirement. Phone + radio simultaneous contact.
  • Level 5 — External Authorities: Police (112), Fire (115), Regional Health Authority (ASL VN-1), Event Insurance Provider (Swiss Re Event Shield). Site Director alone authorised to trigger this level.
