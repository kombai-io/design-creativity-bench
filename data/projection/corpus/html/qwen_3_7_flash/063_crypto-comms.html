Style Conventions v3.1 — Effective Sep 1, 2025
Token Names: Capitalize first letter (MERIDIAN). Contract addresses: always prefix with 0x, show full 42-char hash on first reference, abbreviate to 0xAb…CdEf thereafter. Protocol names use camelCase (meridianBridge, meridianDAO). Network names: lowercase unless proper noun (ethereum, solana, polygon). Dollar amounts: $X.XX format, specify currency when ambiguous. Yield/APY: never state as fact — use "projected," "estimated," or "historical." Staking: distinguish between liquid, locked, and delegated. Governance: refer to proposals by number (#47) and title, not just "the next vote."
Prohibited Phrases
  • "The best protocol in crypto" → Use specific comparative metrics instead
  • "Risk-free" → Never used. DeFi inherently carries risk.
  • "We're going to moon" → Informal, unprofessional, potential securities implication
  • "HODL" → Outdated community jargon. Use "retain position" or "hold."
  • "To the moon" → Avoid hyperbolic price-related language entirely.
  • "Best in class" → Unsupported superlative. Provide benchmarks.
  • "Financial advice" → Never include. Add standard disclaimer.
  • "Will make you rich" → Violates multiple compliance guidelines.
